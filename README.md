# Work Management Application (Android)

Professional Work Management Android Application built with Flutter, Riverpod, GoRouter, and Supabase.

---

## 📌 Project Overview
A multi-user Android application designed for business owners and administrators to track customers, manage work orders/tasks, log work sessions with live timers, record payments, view history, generate reports, and synchronize data in real-time across multiple devices.

---

## 🚀 Key Features
* **Role-Based Access Control:** Secure Owner and Admin permissions.
* **Customer Management:** Track client contact details, active works, and payment balance.
* **Work & Task Tracking:** Real-time task progress, status transitions (Pending, In Progress, Completed, Billed).
* **Work Session Timer:** Live timer for tracking work hours.
* **Payment Management:** Advance tracking, partial payments, receipts, and payment history.
* **Reports & Analytics:** Work summaries, earnings, pending collections.
* **Bilingual UI:** Instant switching between English and Tanglish (Tamil written in English script).
* **Multi-User Realtime Sync:** Live PostgreSQL database updates powered by Supabase Realtime.

---

## 🛠️ Technology Stack
* **Client Framework:** Flutter (Dart)
* **State Management:** Riverpod
* **Routing & Navigation:** GoRouter
* **Design System:** Material Design 3
* **Backend Platform:** Supabase
* **Database:** PostgreSQL with Row Level Security (RLS)
* **Realtime Protocol:** WebSocket-based Supabase Realtime
